# r/Kcet Wiki

This is the central repository for the r/Kcet subreddit wiki. We host the markdown files here to keep our wiki structured, version-controlled, and open for community contribution.

---

## Contribution Rules

- **Keep it clean:** Use standard Markdown formatting.
- **Use new Reddit links:** Always use `www.reddit.com` instead of `old.reddit.com` (mods will update old reddit wiki with correct old subdomain).
- **No piracy:** Do not link to copyrighted, paywalled materials. Keep it free and community-driven.
- **Check your links:** Make sure they work before submitting a PR.
